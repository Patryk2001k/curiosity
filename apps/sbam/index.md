# SBAM — Overview & Quick Start

**Smart Bulk Attachment Manager (SBAM)** gives Jira users and administrators complete control over attachments: filter signature clutter, bulk download organized ZIP archives, and safely manage storage via a virtual Trash Vault.

---

## Quick Start (3 Steps)

### Step 1: Open an Issue or the Global Navigator
* **Single Issue Panel:** Open any Jira issue and expand the **Smart Attachments** panel.
* **Cross-Project Navigator:** In the top navigation or Issue Navigator, select **SBAM — Smart Attachment Manager**.

### Step 2: Filter and Organize
* Toggle the **Smart Anti-Junk Filter** to automatically hide email signatures (<20 KB).
* Use category pills (*PDF*, *Office*, *Images*, *Archives*, *Data*) or the search bar to locate specific files.

### Step 3: Download or Trash
* Choose folder hierarchy preferences (*Per-issue folder*, *Category subfolders*).
* Click **Download Selected (.ZIP)** for zero-latency client-side download, or **Move to Trash** for safe recovery.
